# JSON Formatter Pro

Enterprise-class, fully client-side JSON formatter, validator, and analyzer.
Zero dependencies, zero build step, zero data leaves the browser.

## Features
- Real-time validation with line/column error hints
- Pretty-print with 2/4-space indentation
- Syntax-highlighted output, copy & download, sample loader
- Glassmorphic dark UI, fully responsive

## Usage
Open `index.html` in any modern browser. `Ctrl/Cmd+Enter` formats.

## Deployment
Static hosting only — GitHub Pages, Netlify, Vercel, or any web server:
just upload the folder as-is.

## Security note
All parsing is client-side; no telemetry, network calls, or third-party
requests are made. Do not add hidden reporting endpoints — if analytics
are needed, use an explicit, consent-gated, first-party solution.
